🎵 AUDIO DOWNLOADER - SETUP
═══════════════════════════════════════════

1️⃣ INSTALL FFMPEG (REQUIRED!):
   Windows: https://www.gyan.dev/ffmpeg/builds/
   Mac: brew install ffmpeg  
   Linux: sudo apt install ffmpeg

2️⃣ INSTALL PYTION PACKAGE:
   pip install yt-dlp

3️⃣ RUN THE SCRIPT:
   python audio_downloader.py

📝 HOW TO USE:
   - Select option 1
   - Paste YouTube URL
   - Choose format (1=MP3)
   - Choose quality (3=256k best)
   - Wait for download

✅ Files save to: Downloads folder

❌ FFMPEG ERROR? Install FFmpeg from step 1
